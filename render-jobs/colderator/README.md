# Colderator control render job

Purpose: first reproducible visual prototype for the Colderator knob family.

Visual direction:
- snow-white / ice-white control bodies;
- subtle blue frost shimmer;
- separation from a white panel primarily through soft shadow, highlight and a fine ice-blue ring;
- restrained blue-grey position indicators;
- no dark-metal or MixEngine visual carry-over.

Controls:
- main: large COLD macro, 120 px base frame;
- character: ICE / METAL / FROST / SHIVER / SPACE, 88 px base frame;
- utility: OUTPUT / Atmosphere amount, 72 px base frame.

All controls use 128 frames and deterministic 1x / 1.25x / 1.5x / 2x exports.
The render job performs center-wobble QA before publishing generated assets.

This is a visual prototype source, not yet an approved permanent built-in Designer preset.
